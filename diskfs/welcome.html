Welcome to SavanXP

This is a sample page for Web Viewer, the minimal HTML viewer of SavanXP. If you can read this, the local file flow works: Files opened this page, the viewer parsed it and painted it.

What it renders

  • Headings, paragraphs and line breaks
  • Lists like this one
  • Rules and entities such as & and <tag>

What is not here yet

DNS, CSS, images and background loading arrive in later milestones. Name hosts stay unreachable until DNS lands.
